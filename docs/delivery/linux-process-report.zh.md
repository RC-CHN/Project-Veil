# Linux 成品双端交付报告

日期：2026-09-16。版本：0.5.0-engineering2。对应 [Linux 交付计划](linux-first.zh.md) 第一批；操作入口见 [成品双端操作](../operations/linux-process.zh.md)。

## 交付范围

正式 CLI 已增加初始双端材料准备、实际 SOCKS TCP/UDP 回显诊断、带运行实例身份的周期状态及显式字节预算配置。验收使用构建后的 veild/veilctl、私有磁盘配置/证书和独立客户端/服务端进程，业务经过真实 TLS/h2。

prepare 在新私有目录中分开 client/server/admin，校验服务端身份并生成独立客户端 CA 与身份；不覆盖已有输出，不执行 ACME 或在线换证。LocalReady 和配置检查不代表远端健康；probe 仅报告指定回显目标的验证结果。运行仍是前台进程，不依赖 systemd、Docker 或 Python。

默认每流 8 MiB / 每承载 64 MiB 未变。新增配置仅开放原运行库已有的有限累计字节上限，双端取较小值；窗口、队列、并发、OPEN 和确认语义保持既有约束。显式较大预算用于验证较大传输的完整性，性能优化未恢复。

## 验证

最终成品进程验收 **24/24 通过**。同一 TCP 连接和同一 UDP 关联持续 260.009 秒，各完成 258 次回显操作；服务端被杀后旧 TCP 流终止，客户端进程保持不变，新 TCP/UDP 探测恢复。13 个节点进程均已退出，其中一次 SIGKILL 为明确注入的故障；其余正常停止的最终状态均无活动流、活动承载或清理失败，临时私有材料已删除。

错误客户端身份、错误模型种子、不安全配置权限及目的地策略负例均拒绝。身份/模型负例期间，独立目标见证计数未增加，恢复正确材料后的新探测通过。

## 适用边界和下一步

本次是 Linux 回环网络上的正式进程验收，没有独立主机、网络命名空间或公网 VPS。域名用例由服务端访问自有 DNS 夹具，不能替代真实公网 DNS 行为；IPv6 业务路径未做本轮成品验收。

260 秒持续连接不能替代全天耐久，也未单独统计模型执行代次交接次数。当前 stdout 状态需要外部及时消费，没有完整事件分段归档、运行日志轮换或磁盘预算。身份默认期限及准备失败的暂存目录处理见操作说明；尚未做宿主断电持久性或 OpenWrt/Windows 原生验收。

预算耗尽和服务端退出都会中断受影响流；后续新连接恢复不意味着旧业务透明续传。下载用例同时核对长度和 SHA-256，不能仅凭 EOF 或本地写入完成宣称业务完整。

下一批优先实现 Linux 安装和服务管理：目录与运行身份、版本绑定、systemd 适配、启动/就绪检查、日志消费、停止/卸载和真实机器重启。随后接入 TUN/DNS、系统网络保护、ACME 与身份/升级恢复，再做受控公网双机和全天验收。服务与网络的共用合同保留 OpenWrt 适配边界。
